# 1.0.25 正式版（2026-10-26）

2026-10-26，用户反馈朋友手机测试正常，并明确授权正式打包和部署腾讯云。本次正式包与已发送的手机测试包逐字节一致，包含失效实体延迟回调、睡眠回血参数和向上射击时箭体姿态调整。以下保留修复依据及测试阶段的验证边界。

## 实体生命周期与睡眠

`main.js` 中 7 处实际延迟回调改用 `entity-lifecycle.js` 的 `runEntityTimeout`，在任务执行时调用当前 API 1.x 的 `entity.isValid()`。覆盖龙眼标签清理、投射物命中后的闪避标签清理、死亡恢复与初始化的隐身标签清理，以及两处睡眠回血任务。保留原延迟和在线玩家的处理；不吞掉与实体离线无关的异常。上游主体只作精确替换，不重新格式化、压缩或重命名混淆符号。

两处睡眠回血调用原来传入 `(..., 0x14, false)`，把布尔值传给了 amplifier。改为 `(..., 0x14, 0, false)`，明确使用数字倍率和关闭粒子。测试提取包内实际回调及原效果函数，在排队后使玩家失效，确认不再访问实体；玩家在线时确认回血参数为数字。

这修复了明确的代码缺陷，不代表已查明玩家被迫退出的根因。原日志顺序为玩家先断开，约 74ms 后才出现 removeTag 错误。

## 长弓箭体姿态

四种长弓对应的三类箭使用独立模型。原模型的箭身、贴图 UV、比例及粒子定位点保留，新增 `longbow_yaw` 父骨骼控制水平转向；`body` 子骨骼只负责俯仰，从层级上明确先处理俯仰，再处理偏航。原共享模型、三叉戟和蛛网动画不变；`longbow.js`、弹道、伤害及附魔组件不变。

角度仍来自实际位移；首帧保留原版目标角度回退，停下后保留最后姿态。几何层级依据官方骨骼继承规则：
https://learn.microsoft.com/en-us/minecraft/creator/documents/animations/animationsoverview

原测试直接用一个理想化的 yaw/pitch 公式计算方向，没有读取模型层级。新测试读取包内实际模型和动画、逐骨骼复合矩阵，同时检查 XYZ 与 ZYX 两种组合约定，覆盖每 15 度一个方位及 -90 至 +90 度的 14 个仰角（含 5、15、30 度上射），以及垂直、停止和首帧状态。旧 1.0.24 的三个模型在 XYZ 模型化变换下失败、ZYX 下通过；本候选两种约定均通过。

**验证边界：测试阶段尚未证明玩家设备实际采用的变换路径，数学失败不等同于实机复现。2026-10-26 用户反馈朋友手机测试正常，允许正式发布；没有新增录像、设备日志或独立客户端复测来确定具体的引擎原因。**
