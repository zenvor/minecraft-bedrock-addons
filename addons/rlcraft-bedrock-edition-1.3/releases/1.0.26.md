# RLCraft 1.3 简体中文版 1.0.26

2026-11-05 正式发布并部署到腾讯云“RLCraft 新纪元”。修复 RLCraft 结构 feature 对 BOP 树叶的错误引用。

## 修复内容

139 个 `minecraft:structure_template_feature.constraints.block_intersection.block_allowlist` 将不存在的 `4ks_bop:origin_leaves` 改为 BOP 实际注册的 `4ks_bop:origin_oak_leaves`。每个文件只替换一次标识符，其余字节不变。

该问题会在结构与 BOP 树叶相交判断时产生未知方块错误，并阻止相应放置；不能据此认为所有结构都无法在空气中生成。没有改动结构文件、脚本、生物、贴图或其他游戏规则，BOP 的 14 个 legacy mcstructure 保持原样。

BP/RP header、data/resources module 及交叉依赖同步为 1.0.26。UUID、BP script module 1.3.0、`@minecraft/server` 1.15.0、`@minecraft/server-ui` 1.1.0 及最低引擎要求均保持原值。
