# RLCraft 1.3 简体中文版 1.0.24

2026-10-23 正式部署到腾讯云“RLCraft 新纪元”，接续正式版 1.0.23。修复源码提交为 `4fb6939b`。

用户确认测试包 1.0.28 可用后，要求将其内容以 1.0.24 作为正式版发布。测试阶段的 1.0.24 至 1.0.28 是候选编号；正式版 1.0.24 不等于早期同号候选包。

## 修复内容

- 为根须长弓、龙骨长弓、余烬裂响和寒霜裂响开放弓类附魔，并补齐力量、冲击、火矢及无限的射击处理。
- 增加触屏拉弓中央准星，取消使用、切槽和死亡重生时清除。
- 调整三类自定义箭的飞行姿态计算，修正此前错误抵消实体偏航的逻辑。
- 将三类箭的拾取感应器改为新版 `subsensors` 与 `range` 结构，兼容当时 BDS 的实体格式。

后续反馈的向上射击箭体姿态，以及失效玩家回调和睡眠回血参数问题，由 [1.0.25](1.0.25.md) 继续处理；本记录不将这些后续问题视为 1.0.24 已解决。


工具从该提交读取源码，产物输出到 `dist/`。工具保留 `rat-fix` 的历史文件命名，生成包可重命名为上述正式文件名；包内容与 SHA-256 不因文件名变化而改变。
