## BDS 包格式

`.mcaddon` 是外层分发包，里面包含两个 `.mcpack`：

- `RLCraft-1.3-behavior-pack-1.0.23.mcpack`
- `RLCraft-1.3-resource-pack-1.0.23.mcpack`

两个 `.mcpack` 都是 ZIP，根目录直接有 `manifest.json`。BDS 部署应将它们分别解压为行为包和资源包目录，再更新世界对相应包的引用。包可位于服务器顶层或世界内部的 `behavior_packs` / `resource_packs` 目录，见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/minecraft/creator/documents/bedrockserver/getting-started?view=minecraft-bedrock-stable#shared-resource-and-behavior-packs)。不要只把压缩文件放进目录等待服务器自动导入。

只更新世界现有 RLCraft 条目的版本，保留其他包及顺序：

## 重建

在仓库根目录执行：

```sh
python3 addons/rlcraft-bedrock-edition-1.3/tools/pack.py --ref 3105091af5044e6c575ef9064bd8273617a43791
```

工具从指定 Git 提交读取源码，不包含工作区的未提交改动，不重新压缩 JavaScript。外层包输出至 `dist/`，两个内包及审计记录输出至 `.build/rlcraft-rat-release/`。历史构建包不再保留在当前源码树，需要回滚时从上述源码提交重建并核对本记录中的 SHA-256。
