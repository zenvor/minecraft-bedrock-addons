# RLCraft 1.3 简体中文版 1.0.25

2026-10-26 正式发布并部署到腾讯云“RLCraft 新纪元”。用户反馈朋友手机测试正常；正式包与手机测试包逐字节一致。

## 修复内容

- 7 处玩家延迟回调在执行时检查实体有效性，避免离线后访问失效实体。
- 修正两处睡眠回血调用的药水倍率参数类型。
- 为四种长弓的三类箭建立独立模型，将偏航和俯仰分到父子骨骼，调整向上射击时的箭体姿态。发射、弹道、伤害和附魔逻辑不变。

玩家被迫退出的根因仍未确定；不能将失效实体异常的修复等同于解决所有掉线。
