# Biomes O’ Plenty 简体中文版 1.0.12

2026-11-05 发布为本项目正式版。包内容与 2026-11-04 部署至腾讯云 BDS 1.26.61.1 的 1.0.12 测试包逐字节一致。观察日志没有新增 BOP Watchdog Hang 或关键脚本异常；原有内容错误和其他模组故障见下文。

## 修复内容

- 将树苗生长前的空间检查从脚本逐方块查询改为 `BlockVolume` 配合原生 `dimension.getBlocks`，减少大树检查时的脚本与引擎交互。
- 保留第一个方块的快速拒绝，避免首处被阻挡时仍扫描整个体积。
- 保持原有体积边界、坐标取整、配置偏移、`ignoreY` 下层忽略和仅允许空气的判定。未加载区块拒绝生长，其他异常继续抛出。
- 不改自然生长周期、概率、树形权重、结构放置或骨粉消耗逻辑。仅修改 BOP 主脚本中的净空检查及所需 API 导入。

本修复消除了已测空间检查的性能瓶颈；现有日志不能证明 2026-11-03 BOP Watchdog Hang 当时就发生在该函数，不能表述为所有历史卡顿、掉线或崩溃已解决。

## 已完成验证

- 11 组本地专项回归通过，覆盖 354 个结构配置的坐标语义及 2,832 个边角阻挡组合。
- 相同 BDS 引擎下，原版与候选版分别完成 19/19 生长流程用例，包括原生自然 tick、概率拒绝/成功、单棵和 2×2 最大树形、阻挡、偏移、部分未加载区块、骨粉消耗、重复交互及失败后保留树苗。
- 每版 11 次结构落地核对，共 4,316 个模板定义方块类型，差异为 0。骨粉使用真实订阅回调与原生容器适配器注入，没有真人客户端点击验收；未验证全部方块状态和全部树形的原生落地。
- 最大 2×2 成功用例的完整入口单次耗时由 170ms 降至 5ms。计时分辨率 1ms，单次观测不等于线上性能分布。
- 1.0.12 BP/RP 依赖加载与单棵、最大 2×2 生长冒烟 2/2 通过。
- 归档可复现性、外/内包 CRC、路径安全、源码逐文件一致性通过。相对 1.0.11 仅主脚本及两个 manifest 改变，未增删资源。
- 语言结构无错误；原有 RP 两条 `~LINEBREAK~` 标记警告保留，不能将严格语言检查描述为全绿。

隔离测试中曾发生命令处理受内存回收限速阻塞：`MC_SERVER` 在 `stop` 前进入 `mem_cgroup_handle_over_high`。这是实际等待证据，不能将测试超时直接解释成 BOP 停服死锁。完整 BOP 在充足资源下正常退出的对照尚未完成。

## 部署后观察与发布状态

观察区间：2026-11-04 13:45:57 至 2026-11-05 15:16:22（UTC+08:00）。启动包栈和重启后的包栈均加载 BOP 1.0.12，线上主脚本与候选包一致。

- 观察窗口内没有发现新的 BOP Watchdog Hang 或关键脚本异常。
- 仍有 25 条 `[Json] Unknown block during Deferred BlockDescriptor resolution: 4ks_bop:origin_leaves` 内容错误；部署前已存在相同错误，本次净空检查优化未修改相关定义，也未修复此已知问题。
- 2026-11-05 00:41:20，Watchdog 明确记录 `28606 ms hang detected in 'Mowzie's Mobs'`，随后发起服务器关闭。
- 00:41:27，原进程以退出码 6 结束；00:41:39，systemd 自动重启服务器，重启计数为 1。
- 检查到的同区间内核日志没有 OOM/kill/segfault 事件。日志目前将本次 Hang 标记到 Mowzie’s Mobs，尚未定位其具体函数和触发操作，不将其归因于 BOP。

本版本按 BOP 自身的修复和观察结果正式发布。Mowzie’s Mobs 的 Watchdog 故障另行排查，不作为 BOP 1.0.12 的已知回归。该记录不表示整服从未崩溃，也不能保证所有历史 Hang 已被根治。

详见[正式版验证记录](../verification/release-1.0.12/report.md)。完整原始诊断日志保留在本地验证目录，正式发布仅附带本次修复所需的汇总证据。

## 重建正式包

```sh
python3 addons/biomes-o-plenty/tools/pack.py
```

工具从当前 `source/` 读取内容，保留脚本字节并进行两次确定性归档构建，输出 `dist/Biomes-O-Plenty-zh_CN-v1.0.12.mcaddon`。将其 SHA-256 与本页记录比较后即可复核正式产物。
