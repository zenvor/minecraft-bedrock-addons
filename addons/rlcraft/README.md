# RLCraft Bedrock Edition

该目录保存 RLCraft 基岩版 `v1.2.0` 的可追溯修复与平衡性调整工作集。

- `source/`：待部署 `v1.2.3` 性能与平衡性版的行为包与资源包源码；行为包内部版本为 `1.0.22`，脚本模块为 `1.2.3`。
- `upstream/`：原始 `.mcaddon` 与地图模板，保持不改动，供逐文件比对。
- `docs/`：Watchdog 与性能审计记录。
- `releases/`：已部署的 `v1.2.1` 修复包、待部署的 `v1.2.2` 性能加固包，以及待构建的 `v1.2.3` 平衡性版。
- `tools/`：部署脚本；`tools/archive/` 是已废弃的试验性补丁工具，不可直接运行。

`source/behavior-pack/scripts/main.js` 保持上游混淆形态，已在 Prettier 检查中精确排除；其余仓库附加包不受影响。

`v1.2.3` 在不改动战斗节奏、飞龙死亡后的永久对话和既有探索奖励的前提下，为慰藉泰迪熊增加高成本合成渠道，并只在沙漠专属地下城预设箱子中增加低概率附加掉落。
